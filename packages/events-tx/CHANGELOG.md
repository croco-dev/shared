## 0.2.0

### Minor Changes

- 9784c13: Isolate dead-letter exceptions during outbox batch publication, emit telemetry for poisoned outbox messages, and reflect degraded or failed status on relay batch execution when poison messages occur.

### Patch Changes

- 38cba9c: - fix: enforce full strict contract spine
- b5b2da5: Claim PostgreSQL outbox batches atomically with nonblocking row locks so concurrent workers take disjoint eligible messages. Keep later messages for an aggregate behind pending, publishing, or retrying predecessors in creation-time and ID order, including during retry delays and lease recovery.
- 7cdfcae: Declare audited package side effects so bundlers remove pure imports while preserving required initialization and CSS.
- 5535392: Allow transactional outbox relays to stop intake, cancel active publication, release unstarted claims, and report bounded shutdown drain outcomes.
- a72e2f2: - fix: keep punctuation-bearing inbox identities distinct
- 90b3517: - fix(events-tx): allow inbox completion when lease expires without reclaim
- d20f4eb: Prevent stale transactional inbox workers from overwriting newer retries or terminal records by requiring the accepted attempt claim on completion.
- 67e0cbe: fix: resolve published package types before runtime conditions
- 852de2d: Replay an existing outbox message when the same idempotency key, event identity, payload, and metadata are retried with a different occurrence timestamp. Preserve the first stored timestamp and continue rejecting changes to eventId, eventType, aggregateId, payload, or metadata.
- 88d8bcc: Preserve the original inbox handler failure when persisting failed inbox state also fails, while retaining the persistence failure as diagnostic evidence.
- 157089a: Remove package-local registry publish commands so releases can only write through the protected Changesets workflow.
- 5d54fb4: declare Apache-2.0 license across all publishable package manifests and ship LICENSE in published packages
- 51cf890: Make interrupted inbox processing reclaimable through expiring leases while fencing stale worker completion.
- 92f606b: Reject outbox message ID reuse across idempotency keys with a stable conflict Problem while preserving the original message and lookup indexes.
- 286a5ad: Reject outbox idempotency-key reuse when the canonical event request differs, including concurrent in-memory and Drizzle appends.
- 0b73dd1: Reject malformed persisted transactional inbox and outbox rows with safe storage diagnostics before relay or consumer logic runs.
- 8191e27: Verify transactional event spine smoke coverage for commit dispatch, rollback isolation, retry/poison evidence, and idempotent replay.
- fdb2c90: Reject invalid transactional outbox, relay, retry, and inbox consumer configuration before invoking collaborators, with a typed public Problem that identifies the violated field and constraint.
