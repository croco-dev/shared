# SaaS Backend Framework for AWS Lambda

CROCO is an opinionated TypeScript framework that combines HTTP routing, DDD events, transactions, and **built-in SaaS primitives** (auth, billing, metering, tenant) into a single unified decorator and type system.

> `npx create-croco-app@latest my-saas-api --goal saas-api --scope @myorg --no-install --no-git` → a generated REST SaaS workspace with a zero-credential `pnpm demo:smoke` success path.

## Why Croco?

<div style="display:grid;grid-template-columns:repeat(auto-fit,minmax(280px,1fr));gap:1rem;margin-bottom:2rem;">

**Built-in SaaS Primitives**
Auth, billing, metering, tenant management — all included as first-class packages, not afterthoughts.

**Decorator-First DI**
`@Controller`, `@UseGuards`, `@Metered` — express SaaS logic declaratively with type-safe decorators powered by typedi.

**Lambda-First, Not Lambda-Only**
Bind the same HTTP transport to an explicit Lambda, Node, or Cloudflare Host while keeping build
artifacts independent from runtime lifecycle ownership.

</div>
